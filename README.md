# MyWeek

MyWeek is a lightweight Arabic RTL weekly planner with a personal study companion built for GitHub Pages.

## Study flow

1. Choose a task from the weekly schedule.
2. Press **Start Focus** to open Study Mode and begin a 25-minute Pomodoro.
3. Pause, reset, skip, or finish the session from the timer controls.
4. Completed sessions update task progress, Today's Focus, the daily summary, and the study streak.

Tasks, completion state, focus sessions, streaks, and timer preferences are stored locally in the browser with `localStorage`. No backend or account is required.
